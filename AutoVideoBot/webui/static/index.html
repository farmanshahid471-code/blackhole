Five minute start

1. Check the machine

Click Run health check in the sidebar. You want green lines for python and ffmpeg. Warnings about keys are fine: a video made from your own script with the free voices and the free image service needs no accounts at all.

2. Make a test video

Click Run the 8-second self-test on the Dashboard. It builds a tiny video in about a minute and proves every part of the toolchain works before you spend time on a real one.

3. Build a real one

Go to Create a video, paste a script (or load the example), give it a name and press Build. Watch the log: each of the ten stages explains itself as it runs.

4. Where things end up 
workspace/projects/<your video name>/
    output/final.mp4            ← the video
    output/thumbnail.jpg
    output/youtube_metadata.json ← title, description, tags, chapters
    subs/captions.srt           ← upload to YouTube if you did not burn them in
    images/  clips/  audio/     ← the pieces (kept, so re-runs are instant)

Script format

All four styles work. Everything except the narration is optional.

Timestamps 
[00:00 - 00:12]        a range per scene  (clearest)
Black holes are not empty holes in space.

0:12  one timestamp at the start of the line
00:12 -> 00:25 | arrow style with a pipe

{"title": "...", "scenes": [{"start": 0, "end": 12, "narration": "..."}]}
Scene directives 
@prompt: a supermassive black hole, accretion disk, cinematic
@motion: zoom_in          (or pan_left_right, zoom_out, static...)
@title: The Event Horizon
@pause: 1.2               extra silence after this scene (seconds)
@voice: en-GB-RyanNeural  use a different voice just here
@speed: 1.1               speak this scene 10% faster
@music: tense_dark.mp3    force a specific music track for this scene
@subtitle: off            hide captions on this scene
@skip:                    mark the scene as not-needed
File headers 
#title: Black Holes: The Universe's Most Extreme Places
#description: A short documentary about...
#tags: space, black holes, science
#voice: en-US-GuyNeural
#music: calm_space_ambient.mp3
#style: cinematic, volumetric light
#aspect: 16x9
#language: English

Fixing problems

"ffmpeg NOT FOUND"

Run scripts/install_windows.bat (Windows) or bash scripts/setup.sh (macOS/Linux). Both install a private copy of ffmpeg inside the project, so nothing has to be added to your PATH.

"Edge-TTS unavailable"

That is a network problem, not an installation problem. Check your internet, or build offline with --set tts.provider=test (the tone voice) or piper/espeak. On the Create page you can pick the voice provider per build.

Images all look like dark cards with text

That is the placeholder card. It means the image provider failed for those scenes and the bot deliberately carried on so you still get a video. Open Providers, test your image provider, and read the message it gives you. Common causes: no internet (Pollinations), the Stable Diffusion WebUI needs the --api flag, or a Colab link has expired.

The machine froze or ffmpeg was "Killed"

Out of RAM, almost always the super-sampling. Set motion.supersample to 2 and system.parallel_scenes to 1 in Settings → Advanced. Rendering at 1280×720 instead of 1920×1080 also helps a lot.

Where do I put my own voice / music / logo?

Settings & keys → Add your own files. Music goes to assets/background_music, the watermark replaces assets/watermark.png (enable it with extras.watermark.enabled: true), and fonts land in assets/fonts.
